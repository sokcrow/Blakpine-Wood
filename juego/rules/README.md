# Adaptadores de combate

Ubicación reservada para futuras implementaciones de combate Legacy, DnD y Moon System.

- Los manifiestos declarativos están en `contratos/multimodo/ejemplos/reglas/`.
- Ningún adaptador multimodo está implementado en esta entrega.
- El combate Legacy y las habilidades generales permanecen inalterados.
- Los adaptadores futuros deberán consumir `contratos/multimodo/v1/`, sin duplicar esquemas ni modificar geometría o navegación.
