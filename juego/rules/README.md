# Adaptadores de combate

- **Legacy** conserva la entrada nativa y sus habilidades generales.
- **DnD** se ejecuta con la demo de ciudad moderna, desde el selector en HTTPS.
  Sus dados D20, defensa, resistencia, energía, HP y guardado están aislados.
- **Moon System** continúa bloqueado como `planned`.

En `juego/rules/dnd/fh-dnd-combat.js` están los parámetros iniciales.
No se asumen clases, niveles, críticos automáticos, iniciativa, atributos
permanentes ni edición. Todas estas reglas requieren decisión posterior.
Sombras sigue siendo el único motor para contacto, colisión y navegación.
