# Intérpretes de mundos

Ubicación reservada para futuros intérpretes de ciudad moderna, distopía y villa medieval.

- Los perfiles declarativos actuales están en `contratos/multimodo/ejemplos/mundos/`.
- No hay generadores, mapas nuevos ni sistemas 3D implementados aquí.
- Un intérprete futuro deberá leer los contratos canónicos de `contratos/multimodo/v1/` sin duplicarlos.
