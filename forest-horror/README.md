# Forest Horror — Publicación GitHub Pages

**Juego y editor integrado:** [`index.html`](./index.html)

**Motor 3D separado:** [`engine.html`](./engine.html)

**Biblioteca GLB y visor:** [`biblioteca/visualizador.html`](./biblioteca/visualizador.html). Incluye 78 modelos GLB, texturas integradas, miniaturas y catálogos.

**Mapas JSON:** carpeta [`maps/`](./maps/).

**Fuente modular:** [`downloads/Forest_Horror_Proyecto_Modular.zip`](./downloads/Forest_Horror_Proyecto_Modular.zip).

**Biblioteca fuente:** [`downloads/Forest_Horror_Biblioteca_GLBS.zip`](./downloads/Forest_Horror_Biblioteca_GLBS.zip).

Los archivos GLB están publicados como biblioteca independiente. El motor actual aún usa los modelos de muebles procedurales; conectar el catálogo GLB al editor y al juego es trabajo aparte. El motor Three.js r128 usa CDN por no incluirse una copia local de Three.js en el proyecto original.

Rutas relativas: al publicar bajo una subcarpeta de GitHub Pages, usar `./` para recursos del mismo nivel.
